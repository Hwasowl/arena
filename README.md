# INFINITY — 고죠 사토루 · 아가츠마 젠이츠 · 레제 프로토타입

## 지금 보는 방법

`Gojo-preview.html`을 Chrome 또는 Edge에서 열면 됩니다. 인터넷과 Node 설치가 필요 없는 단일 HTML 파일입니다. WebGL이 필요합니다.

오른쪽 위 **고죠 / 젠이츠 / 레제** 버튼이나 **1 / 2 / 3** 키로 캐릭터를 바꿉니다. 주소 뒤에 `?char=zenitsu` 또는 `?char=reze`를 붙이면 해당 캐릭터로 시작합니다.

**고죠 사토루**

- **전체 스킬 시연**: 아오+아카 → 무라사키 → 아오 단독 → 아카 단독 → 영역전개 → 대시.
- **Q / E — 아오 / 아카 (3초 대기)**: 누르면 바로 나가지 않고, 팔만 든 채 최대 3초 대기합니다. 아오는 오른팔, 아카는 왼팔이며 손바닥에 기운이 모입니다.
  - 대기 중 **다른 쪽 키**: 둘이 합쳐져 무라사키 발사(두 스킬의 비용·쿨타임 모두 소모).
  - 대기 중 **같은 키 다시**: 그 스킬이 즉시 발사.
  - 3초 동안 아무것도 안 누르면 그 스킬이 자동 발사.
  - 아오 구체가 이미 나가 있는 상태에서 아카로 무라사키를 쏘던 기존 연계는 없앴습니다. 대기 중에는 영역전개를 쓸 수 없고 대시는 됩니다.
  - 아오는 근처 표적을 끌어당기고, 아카는 척력탄을 발사합니다.
- **R**: 약 2초 준비 후 무량공처. 영역 연출과 지속 피해.
- **Shift**: 대시. **WASD**: 이동. **마우스 드래그**: 시점 회전.

**아가츠마 젠이츠**: 왼손에 칼집, 오른손은 칼자루를 쥔 발도 자세.

- **E — 벽력일섬**: 2초간 몸을 낮춘 뒤 화면이 흐려지며 전방으로 돌진. 돌진 경로 위의 모든 표적에 피해.
- **Q — 전집중 호흡**: 2초간 집중하는 동안 주변과 머리 위로 낙뢰. 끝나면 12초 안에 벽력일섬을 준비 동작 없이 최대 3번 즉시 사용.
- **R — 화뢰신(漆ノ型)**: 0.8초간 깊게 자세를 낮춘 뒤 벽력일섬보다 10배 빠른 발도 돌진. 경로 위 표적은 지나간 뒤에야 베이며(150 피해), 황색 번개가 용의 형태로 경로를 따라 나타납니다. 반동으로 시전자는 HP 30을 잃고(죽지는 않음) 4초간 이동 속도 -60%, 대시 불가. 브라우저판은 돌진 직후 뒤돌아보며 용과 베이는 표적을 보여줍니다.
- **전체 스킬 시연**: 벽력일섬 → 전집중 호흡 → 즉시 벽력일섬 3연속 → 화뢰신.

**레제**: 인간 상태에서는 Shift 대시와 R 궁극기(변신)만 쓸 수 있습니다. 기본 스킬(Q·E)을 쓰면 최대 체력의 3%를 잃고(죽지는 않음), 대시는 체력을 쓰지 않습니다.

- **R — 폭탄의 악마(변신)**: 턱을 살짝 내리면 화면 아래에 쵸커와 핀 고리가 보입니다. 오른팔을 팔꿈치를 바깥으로 든 채 목으로 올려 고리에 손가락을 걸고, 잠깐 멈춘 뒤 오른쪽으로 홱 당깁니다("팅"). 빈 소켓이 지글거린 직후 머리가 폭발하고 화면이 검게 변했다가 2초에 걸쳐 서서히 돌아옵니다. 주변 적에게 피해(90)와 넉백을 줍니다. 변신하면 **지속 시간 제한이 없고**, 최대 체력의 20%를 회복합니다(풀피면 회복 없음).
- **Q — 폭주대시(변신 후)**: 발밑 폭발로 돌진. 경로 위 적은 폭발과 함께 공중으로 뜹니다(45). 지나간 길에 화약이 남고 1초 뒤 연쇄 폭발(35)합니다. **아무도 맞히지 못하면** 멈추지 않고 몸을 낮춘 채 먼지를 일으키며 조금 더 미끄러집니다.
- **E — 돌려차기(변신 후)**: 즉발이 아니라 약 0.3초 동안 **오른발을 들고 몸을 오른쪽으로 감았다가**, 오른쪽에서 왼쪽으로 세게 감아 찹니다. 시야도 같이 돌아가고 반달 모양 불꽃 궤적이 그려지며, 적중하면 짧은 히트스톱이 걸립니다. 단독 피해 45.
  - **연계**: 폭주대시 직후 **1.3초 안에 E**를 누르면 대시 방향 그대로 18 앞으로 날아가 더 큰 폭발로 마무리합니다(85).
  - 연계가 열려 있는 동안 E 버튼이 "연계 킥"으로 바뀌며 강하게 빛나고, 화면 중앙에 남은 시간과 함께 "E 연계 킥!"이 표시됩니다(고죠의 무라사키 연계와 같은 방식). 슬라이딩 중에도 이어 쓸 수 있습니다.
  - 한 번의 킥에서 표적마다 한 번만 피해를 받습니다.
- **R 다시 — 대폭발(변신 중)**: 4초 동안 도화선이 타들어가며(이동은 가능, 다른 스킬은 불가, 바닥에 위험 범위 표시) 끝나면 넓은 범위에 대폭발(170)을 일으키고 **인간으로 돌아옵니다**. 체력 12%를 소모합니다. 인간으로 돌아온 뒤 폭탄의 악마는 **20초 뒤** 다시 쓸 수 있습니다.
- **전체 스킬 시연**: 변신 → 폭주대시 → 연계 킥 → 단독 킥 → 대폭발.
- 레제의 화약 게이지(에너지)는 더 이상 쓰이지 않고 체력이 자원입니다. Q를 아주 길게 늘리거나 이동 방향을 위로 조준하는 비행은 아직 없습니다(수평 대시).

**캐릭터 외형(Roblox)**: 플레이어 본인의 아바타·옷은 그대로 두고 상징 부위만 붙입니다. 고죠는 안대, 젠이츠는 허리의 칼, 레제는 쵸커(핀 고리 포함)입니다. 레제가 변신하면 원래 머리와 머리 장신구를 숨기고 도화선 머리카락이 달린 폭탄 머리로 바뀌며, 변신이 끝나면 원래대로 돌아옵니다.
- 오른쪽 위 **소리 OFF**를 눌러 사운드를 켤 수 있습니다. 브라우저판은 합성 효과음입니다.
- **연출: 저자극**으로 화면 흔들림과 블러를 줄일 수 있습니다.
- **표적·쿨타임 초기화**로 다시 시작할 수 있습니다.

브라우저판은 연출을 직접 조작하며 검토하는 Three.js 프로토타입입니다. Roblox 엔진 실행 화면이나 실제 멀티플레이 화면이 아닙니다. 표적은 스킬을 사용하지 않으므로 브라우저판에서 적의 스킬 봉인을 체감할 수는 없습니다.

## Roblox Studio에서 이어서 실행

1. `InfinityArena-Gojo.rbxlx`를 Studio에서 엽니다.
2. **Play**를 누르면 경기장과 훈련 표적이 생성됩니다.
3. Q / E / R / Shift로 플레이합니다. 1 / 2 / 3 키나 오른쪽 위 버튼으로 고죠·젠이츠·레제를 바꿉니다. 1인칭 카메라, 손·칼 뷰모델, 스킬 버튼이 들어 있습니다.
4. 실제 PvP는 Studio에서 서버와 두 명 이상의 플레이어로 확인해야 합니다. 이 환경에서는 Studio를 실행하지 않았습니다.

현재 코드는 서버가 에너지, 쿨타임, 아오·아카 3초 대기와 무라사키 합성, 투사체 피해, 아오의 인력, 영역의 지속 피해와 경계를 처리합니다. 영역에 갇힌 대상은 걸을 수 있지만 이 프로젝트의 스킬 사용이 차단됩니다. 처음부터 영역 안에 있던 상대를 포획하며 지속 시간은 7초입니다. 새 스킬 시스템을 추가할 때도 `DomainLockedUntil` 속성을 확인해야 합니다.

캐릭터 선택은 플레이어 속성 `Character`(`Gojo` / `Zenitsu`)로 서버가 관리하며, 서버는 `GojoConfig.Kits`에 없는 스킬 요청을 거부합니다. 젠이츠의 벽력일섬 돌진·경로 피해, 전집중 충전(3회·12초), 화뢰신의 초고속 돌진·지연 피해·반동(자기 피해, `SlowedUntil` 이동 저하와 대시 잠금)도 서버가 판정합니다. 젠이츠 스킬에는 아직 검증된 Roblox 효과음이 연결되어 있지 않습니다.

레제의 변신 상태는 캐릭터 모델 속성 `BombDevilUntil`(변신 중에는 매우 큰 값, 대폭발이나 사망 시 0)로 관리되며, 서버는 변신 중이 아니면 폭주대시·폭발 킥·대폭발 요청을 거부합니다. 폭발 킥(단독·연계), 화약 지연 폭발, 대폭발, 체력 비용, 변신 회복, 20초 재사용 대기, 넉백도 서버가 판정합니다. 넉백은 대상이 플레이어면 해당 플레이어의 클라이언트가 속도를 적용하고, 고정된 훈련 표적은 서버가 포물선 궤적으로 움직입니다. 폭발 연출은 Roblox 기본 `Explosion`(압력 0, 관절 파괴 0)에 네온 파트를 더한 것이고, 핀의 “팅” 소리는 Roblox 내장 `rbxasset://sounds/electronicpingshort.wav`를 높은 피치로 재생합니다. 도화선 지글거림 소리는 Roblox판에 아직 없습니다.

맵은 Play 시 생성됩니다. Studio 편집 화면에서 생성 전 맵이 비어 보이는 것은 현재 구현 방식입니다. 손동작은 게시된 애니메이션 파일 없이 코드로 움직이는 초기 뷰모델이며, 최종 손 리깅·모션 캡처·캐릭터 모델은 후속 제작 대상입니다.

## 파일 구성

- `InfinityArena-Gojo.rbxlx`: Studio용 프로젝트.
- `roblox/default.project.json`: Rojo 프로젝트 정의.
- `roblox/src/ReplicatedStorage/GojoConfig.luau`: 피해량, 비용, 쿨타임 등 조절.
- `roblox/src/ServerScriptService/Combat.server.luau`: 서버 전투 판정.
- `roblox/src/ServerScriptService/Arena.server.luau`: 경기장·표적·캐릭터별 상징 부위(안대·칼·쵸커·폭탄 머리).
- `roblox/src/ServerScriptService/StoreVFX.server.luau`: 선택한 스토어 파티클 연결.
- `roblox/src/StarterPlayer/StarterPlayerScripts/Gojo.client.luau`: 세 캐릭터 공용 1인칭 손·칼·쵸커, UI, 카메라, VFX.
- `preview/`: 수정 가능한 브라우저 미리보기 소스.
- `ASSETS.md`: 외부 에셋과 실제 적용 상태.

Rojo로 소스를 변경한 뒤 빌드하는 명령:

```text
rojo build roblox/default.project.json -o InfinityArena-Gojo.rbxlx
```

## 완료 상태와 남은 부분

- 브라우저 3D 미리보기와 로컬 프로젝트 파일 생성 완료.
- Rojo 프로젝트 빌드 성공.
- Roblox Studio 실행·멀티플레이·모바일 성능 확인은 미실시.
- 스토어 모델은 원본 파일이 로컬 프로젝트에 내장된 상태가 아닙니다. 실행 시 로드하며 권한 또는 에셋 상태에 따라 실패할 수 있습니다.
- 브라우저와 Roblox판은 엔진과 효과 구현이 다릅니다. 동일 화질/동일 타이밍의 최종 검수 전 버전입니다.
- 현재 단계는 3캐릭터 훈련장 프로토타입입니다. 매칭, 승패, 랭크, 저장, 수익화, 완성된 외부 캐릭터 모델은 포함하지 않습니다.
- Rojo가 없는 환경에서 수정한 경우 `.rbxlx` 안의 스크립트 소스를 `roblox/src`와 직접 맞췄습니다. Rojo가 있으면 위 명령으로 다시 빌드하는 것이 정석입니다.

기존 계정으로 획득한 에셋 로딩 조건은 Roblox의 [InsertService 문서](https://create.roblox.com/docs/reference/engine/classes/InsertService)를 따릅니다. 그룹 소유 게임으로 옮기면 권한을 별도로 확인해야 합니다.

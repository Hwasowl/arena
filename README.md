# INFINITY — 고죠 사토루 · 아가츠마 젠이츠 · 레제 · 샹크스 · 도라에몽 · 천도 페인 프로토타입

## 지금 보는 방법

`Gojo-preview.html`을 Chrome 또는 Edge에서 열면 됩니다. 인터넷과 Node 설치가 필요 없는 단일 HTML 파일입니다. WebGL이 필요합니다.

Roblox에서는 오른쪽 위 **고죠 / 젠이츠 / 레제 / 샹크스 / 도라에몽 / 페인** 버튼이나 **1 / 2 / 3 / 4 / 5 / 6** 키로 캐릭터를 바꿉니다. 아래 동작 수치와 설명은 현재 Roblox 구현 기준입니다.

모든 캐릭터가 **마우스 좌클릭(M1) 기본공격**과 **이동 중 Ctrl 슬라이딩**을 사용할 수 있습니다. 화면 오른쪽의 공용 버튼으로도 조작합니다. 컨트롤러는 R2가 기본공격, B가 슬라이딩입니다.

- **기본공격**: 고죠·레제 등은 기존 3연타(준비 0.16 / 0.18 / 0.24초, 타격 0.1초, 회수 0.22 / 0.24 / 0.32초, 피해 12 / 14 / 20)를 사용합니다. 젠이츠는 첫 입력에 0.38초 동안 칼집에서 칼을 뽑고 **오른쪽 → 왼쪽 → 오른쪽 → 왼쪽**으로 천천히 4번 벱니다. 준비 0.52 / 0.32 / 0.32 / 0.32초, 베기 0.24초, 회수 0.30 / 0.28 / 0.28 / 0.34초, 피해 12 / 14 / 16 / 20입니다. 회수 후 0.7초 동안 추가 입력이 없으면 0.42초에 걸쳐 칼을 칼집에 다시 넣습니다. 사거리는 6스터드이고, 한 번에 앞의 한 대상만 맞으며 벽 너머는 맞지 않습니다. 마지막 타격은 넉백을 줍니다. 에너지·체력을 소비하지 않으며 회수 마지막 0.15초에는 다음 입력을 예약할 수 있습니다.
- **슬라이딩**: 지상에서 이동 중 누르면 0.7초 동안 몸과 시야를 낮추고, 수평 속도를 38에서 12스터드/초로 감속합니다. 에너지 6, 재사용 대기 1.4초입니다. 정지·공중·화뢰신 반동 중에는 시작하지 않고, 벽·낭떠러지·점프·사망 시 중단합니다. 슬라이딩 중 공격·스킬은 잠깐 잠기며 끝나면 움직임과 시야가 복귀합니다. Shift의 캐릭터별 대시 스킬은 별도로 유지합니다.
- **웹 검토**: 오른쪽 **기본공격·슬라이딩 시연**에서 젠이츠는 발도→4연타→납도→슬라이딩, 다른 캐릭터는 3연타→슬라이딩을 재생합니다. 웹의 시점 조작은 **우클릭 드래그**, 기본공격은 좌클릭, 일반 점프는 **Space**, 이동 중 슬라이딩은 **Ctrl**입니다. 점프 발구름·착지와 슬라이딩 시작·마찰·종료, 평타 휘두름·실제 적중 시점에 각각 소리를 재생합니다. `#debug`로 열면 일시정지·프레임 진행·캔버스 캡처 버튼을 사용할 수 있습니다.

새 기본공격·슬라이딩은 Luau 문법 검사와 웹 프레임 검사를 했으며, 이번 변경을 Roblox Studio에서 실행하지는 않았습니다. 실제 R6/R15 팔·몸 자세, 슬라이딩 충돌/경사면과 사운드는 Studio에서 확인해야 합니다.

**고죠 사토루**

- **전체 스킬 시연**: 아오+아카 → 무라사키 → 아오 단독 → 아카 단독 → 영역전개 → 대시.
- **Q / E — 아오 / 아카 (3초 대기)**: 누르면 바로 나가지 않고, 팔만 든 채 최대 3초 대기합니다. 아오는 오른팔, 아카는 왼팔이며 손바닥에 기운이 모입니다.
  - 대기 중 **다른 쪽 키**: 둘이 합쳐져 무라사키 발사(두 스킬의 비용·쿨타임 모두 소모).
  - 무라사키는 팔을 원으로 돌리면서 실제 캐릭터가 약 2.4초 동안 최대 12스터드 상승합니다(천장이 있으면 상승 제한). 2.85초에 두 구체가 화면 앞에서 합쳐지고, 3.6초에 머리 높이에서 조준 방향으로 발사됩니다. 발사 후 0.45초 동안 공중 자세를 유지한 뒤 내려옵니다. 발사 속도는 105스터드/초이며, 벽·기둥을 관통해 사거리 170스터드까지 날아갑니다.
  - 대기 중 **같은 키 다시**: 그 스킬이 즉시 발사.
  - 3초 동안 아무것도 안 누르면 그 스킬이 자동 발사.
  - 아오 구체가 이미 나가 있는 상태에서 아카로 무라사키를 쏘던 기존 연계는 없앴습니다. 대기 중에는 영역전개를 쓸 수 없고 대시는 됩니다.
  - 아오는 근처 표적을 끌어당기고, 아카는 척력탄을 발사합니다.
- **R**: 약 2초 준비 후 무량공처. 영역 안에서는 지속음이 반복되고 밖으로 나오면 멈춥니다. 7.5초 만료 시 닫힘음, 다른 영역과 겹쳐 깨질 때 파괴음이 납니다. 겹치는 영역을 두 명이 전개하면 서버에서 더 늦게 시전을 시작한 쪽이 승리하며 기존 영역의 피해·스킬 잠금·화면 효과를 즉시 끝냅니다. 영역 연출과 지속 피해는 승리한 영역에서만 이어집니다.
- **Shift**: 대시. **WASD**: 이동. **마우스 드래그**: 시점 회전.

**아가츠마 젠이츠**: 왼손에 칼집, 오른손은 칼자루를 쥔 발도 자세.

- **E — 벽력일섬**: E를 누르는 동안 몸을 낮추고 번개를 모읍니다. 놓으면 즉시 발도하며, 짧게 누르면 10스터드, 1.6초 풀차징이면 40스터드까지 이동합니다. 돌진한 자리에는 낙뢰와 반투명 잔상이 남습니다. 차징 길이와 관계없이 피해는 70이며, 발도한 뒤 6초 쿨타임이 시작됩니다. 차징해도 쿨타임이 초기화되지 않습니다.
- **Q — 전집중 호흡**: 2초간 집중하는 동안 주변과 머리 위로 낙뢰. 끝나면 12초 안에 벽력일섬을 **연속 3회** 사용할 수 있습니다. 세 번을 자동으로 돌진하지 않으며, 매번 E를 누르고 놓아 각각 10~40스터드를 충전합니다. 첫째·둘째 발도 뒤에는 0.5초 연계 대기, 셋째 발도 뒤에는 6초 쿨타임이 돌며 각 발도의 피해는 똑같이 70입니다.
- **R — 화뢰신(漆ノ型)**: 0.8초간 깊게 자세를 낮춘 뒤 벽력일섬보다 10배 빠른 발도 돌진. 경로 위 표적은 지나간 뒤에야 베이며(150 피해), 황색 번개 용이 경로 위에서 굽이치며 나타납니다. 용의 머리·뿔·몸통은 기존 대비 2.5배 크기입니다. 반동으로 시전자는 HP 30을 잃고(죽지는 않음) 4초간 이동 속도 -60%, 대시 불가. 웹판처럼 돌진 후 시전자가 뒤돌아보며 용과 베이는 표적을 보여주고, 베기와 반동도 시야가 돌아간 다음 발생합니다. 캐릭터는 일직선으로 돌진하고 몸의 방향은 유지합니다. 실제 도착 위치가 반영된 뒤 0.08초 기다리고, 카메라만 0.65초간 뒤로 돌아 경로보다 7스터드 높은 용을 왼쪽 위에 보여준 뒤 정상 조작으로 복귀합니다.
- **전체 스킬 시연**: 벽력일섬 풀차징 → 전집중 호흡 → 각각 준비하는 벽력일섬 3회 → 화뢰신.

**샹크스**: M1 기본공격·Ctrl 슬라이딩·Shift 대시를 공용으로 사용합니다. Q와 R은 패기를 쓰는 만큼 에너지를 소모합니다. E는 3초 동안 선택지를 열어둡니다.

- **Q — 패기 발현**: 0.5초 동안 시야 주변에 붉은 번개가 치며 화면이 흐려진 뒤 발현합니다. 반경 10스터드 안의 적에게 확정 피해 10을 1초 간격으로 두 번 줍니다. 에너지 20, 재사용 14초.
- **E — 내지르기 / 반격**: 에너지 12, 재사용 8초. E 뒤 좌클릭은 살짝 떠오르며 전방으로 돌진해 사선으로 베기(35 피해). 우클릭은 칼을 오른쪽으로 낮추고 1초 동안 모든 전투 피해를 무시합니다. 이 시간에 공격을 받아내면 칼이 빛나며 앞찌르기(45 피해)를 합니다.
- **R — 카무사리(神避)**: 칼을 뒤로 빼고 1초간 기를 모은 뒤 폭 5스터드·길이 최대 50스터드 파동을 발사합니다(50 피해). 에너지 40, 재사용 20초.
- **전체 스킬 시연**: 패기 발현 → 카무사리 → E 내지르기.

**도라에몽**: 원래 아바타에 흰 배 패치·흰 반달 주머니와 빨간 목깃·노란 방울을 붙입니다. 대나무 헬리콥터는 노란 축과 두 날개로 만들었으며, 비행할 때만 머리에 나타납니다. 주머니는 몸의 위치·방향을 따르고 시점에는 고정되지 않습니다. 1인칭에서 고개를 내리면 원래 아바타의 옷을 입은 몸통과 주머니가 함께 보입니다.

- **Q — 4차원 주머니**: 0.18초 동안 고개를 잠깐 내려 자기 배의 주머니 입구와 실루엣을 봅니다. 0.12~0.32초에 왼손으로 입구를 잡고, 0.32~0.98초에 오른손을 넣어 좌우·위아래로 뒤적입니다. 0.98초부터 도구를 꺼내며 1.34초까지 시선을 원래 조준으로 돌린 뒤 1.75초에 사용하며, 0.45초 동안 손을 회수합니다. 에너지 12, 재사용 5초입니다. 스몰라이트는 조준한 상대의 크기와 공격력을 2초간 40% / 30% 낮춥니다. 공기포는 0.38초에 걸쳐 상대를 20스터드 밀칩니다. 기본 피해 10, 밀리는 도중 실제 벽에 부딪히면 추가 20으로 총 30 피해를 줍니다. 단팥빵은 체력을 20 회복합니다.
- **E — 대나무 헬리콥터**: Q와 같은 주머니 뒤적임 뒤 0.98초부터 노란 헬리콥터를 꺼내고, 1.5~2.05초에 오른손으로 머리 위에 꽂습니다. 장착이 끝난 순간부터 정확히 3초 동안 비행합니다. WASD로 이동, Space로 상승, Ctrl로 하강하며 입력을 놓으면 떠 있습니다. 종료 후에는 중력으로 내려옵니다. 에너지 18, 재사용 12초입니다.
- **R — 어디로든 문**: 주머니를 뒤져 작은 분홍 문을 꺼내고, 1.45초에 앞에 펼친 뒤 1.72~2.12초에 손잡이가 달린 문짝을 왼쪽 경첩으로 엽니다. 2.3초에 문을 통과해 조준 방향으로 최대 24스터드 이동합니다. 벽 앞에서는 충돌 지점 직전에 멈춥니다. 에너지 28, 재사용 18초입니다.
- **전체 스킬 시연**: 주머니 랜덤 도구 → 대나무 헬리콥터 → 어디로든 문.

**천도 페인(天道 ペイン)**: 원래 아바타에 윤회안(양쪽 눈의 보라색 동심원 고리)과 아카츠키 소매(검은 소매·빨간 구름)·검은 손톱만 붙입니다. 1인칭에서는 손가락 마디·손바닥·손목이 스킬마다 따로 움직이는 전용 팔을 쓰며, 평소에는 팔을 낮게 두고 걸을 때 흔듭니다. 윤회안은 시전 중 밝아지고 R에서 가장 강하게 빛납니다. 모든 판정·피해·넉백·봉인은 서버(`PainServer`)가 정하고, 클라이언트는 연출만 합니다.

- **Q — 신라천정(神羅天征)**: 0~0.45초 동안 고개를 숙이고 오른 손바닥을 가슴 앞으로 올리며 손가락을 하나씩 폅니다(이동 25%, 점프·대시 불가, 비네트·낮은 공명음·FOV 축소). 0.45초에 손바닥을 밀어 투명하게 굴절하는 구형 충격파(흰 테두리·회색 먼지·튀는 돌)를 0.25초 동안 반경 25로 퍼뜨립니다. 파면이 닿는 순간 30 피해와 (적−시전자) 수평 방향 넉백 18~35스터드(가까울수록 강함), 살짝 띄움, 약 0.6초 조작 불가. 벽에 부딪히면 그 자리에서 멈추고 벽 균열·파편과 함께 5 추가 피해. 범위 안의 작은 투사체(아카)는 지웁니다. 한 번의 시전에 대상당 한 번만 맞습니다. 뒤로 0.7초 무방비, 1.5초 이동 25% 감소. 재사용 12초.
- **E — 만상천인(萬象天引)**: 화면 중앙 기준 55스터드·12° 안에서 보이는 한 명을 고릅니다. 없으면 짧게 손을 쥐는 실패 동작 뒤 1.5초 재사용. 맞으면 대상에 보라색 윤회안 조준 고리가 뜨고, 0~0.35초에 오른팔을 뻗어 갈고리 손을 만들며 카메라가 앞으로 당겨지고 대상 주변 공기가 굴절합니다. 대상은 순간이동 없이 발이 뜬 채 몸이 기울어 처음엔 빠르게, 끝에선 느리게(최대 0.8초) 시전자 앞 4스터드까지 끌려옵니다. 끌려오는 동안 이동·점프·대시 불가, 뒤로 보라색 입자가 흐릅니다. 벽에 막히거나 대상이 죽거나 범위를 벗어나면 취소됩니다. 도착하면 왼손에 검은 차크라 수신봉이 생겨 찌르기 25 피해, 6스터드 넉백, 0.5초 경직. 재사용 14초.
- **R — 지폭천성(地爆天星)**: 0~0.8초 제자리에서 양손으로 보라 고리가 감긴 검은 핵을 모읍니다(심장 박동 같은 중력음, 발밑 자갈이 떠오름). 0.8~1.5초 핵을 앞쪽 20·위 45스터드로 쏘아 올리고 카메라가 따라갔다가 돌아오며 보라색 중력파가 퍼집니다. 1.5초부터 반경 45 장이 생겨 적을 느리게 하고, 2초부터 가까운 최대 4명을 버둥거리며 핵 쪽으로 나선형으로 끌어올립니다(끌려가는 동안 10 피해 ×2). 2.5~4.5초에 실제 3D 바위(작은 것은 빠르게, 큰 것은 느리게)가 회전하며 나선으로 올라와 핵에 붙어 거대한 암석 구체가 되고 바닥에 임시 크레이터가 남습니다. 4.5초에 대상은 구체 안에 숨겨지고(서버가 계속 관리) 1초 동안 압축되며 균열에 보라 빛이 찹니다. 5.6초 붕괴 폭발로 55 피해(최대 합계 75), 살아남은 대상은 안전하게 떨어져 잠깐 넘어집니다. 시전 중 받는 피해 30% 감소·경직 저항, 끝나면 1초 이동 40% 감소와 흐림. 재사용 80초.
- **연계**: E → Q, E → R, Q → R. 앞 스킬이 끝나면 2.5초 동안 이어 쓸 버튼이 빛나고 화면 중앙에 남은 시간이 뜹니다. 쿨타임은 초기화되지 않습니다.
- **전체 스킬 시연**: 만상천인 → 신라천정 연계 → 지폭천성. 프리뷰는 페인을 고를 때만 표적이 8개로 늘어나고(벽 충돌 확인용 배치 포함), 다른 캐릭터로 바꾸면 기존 3개로 돌아갑니다.
- **프리뷰 축척**: 브라우저 프리뷰의 몸 크기는 Roblox 캐릭터의 약 0.6배라 거리 수치를 0.6배로 줄였습니다(Q 반경 15, E 사거리 33, R 핵 높이 27). 시간 값은 같습니다. 프리뷰 효과음은 WebAudio 합성음이며, Roblox판 `PainVFX.Sounds`는 임시 SoundId라 업로드한 효과음으로 바꿔야 합니다.

**레제**: 인간 상태에서는 M1 기본공격·Ctrl 슬라이딩·Shift 대시·R 변신을 쓸 수 있습니다. 변신 후 기본 스킬(Q·E)은 각각 최대 체력의 3%를 소모하고(죽지는 않음), M1·슬라이딩·대시는 체력을 쓰지 않습니다.

- **R — 폭탄의 악마(변신)**: 턱을 내리고 쵸커 핀을 당깁니다. 오른팔을 목으로 올려 고리에 손가락을 걸고 잠깐 멈춘 뒤 오른쪽으로 홱 당깁니다(“팅”). 핀을 뽑은 직후 머리가 폭발하고 화면이 검게 변했다가 2초에 걸쳐 돌아옵니다. 주변 적에게 피해(90)와 넉백을 주며, 최대 체력의 20%를 회복합니다. 변신은 제한 시간이 없습니다.
- **Q — 상승 폭발 / 내려찍기(변신 후)**: 처음 누르면 약 0.4초 웅크렸다가 발밑 폭발과 함께 앞 대각선으로 높이 솟습니다(이전보다 약 3배 높음). 상승 중 Q를 누르면 아래로 급강하해 착지하며, 바닥에 `/\` 모양의 불꽃 궤적과 충격파를 남깁니다. 내려온 직후 시야가 잠깐 바닥을 향하고 0.2초 뒤 앞을 봅니다. 내려찍기는 주변 적에게 피해(65)와 넉백을 줍니다.
- **E — 오른손 폭발(변신 후)**: 오른손을 들어 앞으로 뻗는 데 약 0.2초, 손을 뻗은 채 0.8초 기다린 뒤 전방 약 3블럭(스터드) 지점에서 폭발합니다. 주변 적에게 피해(55)와 넉백을 줍니다.
- **R 다시 — 대폭발(변신 중)**: 4초 퓨즈가 타는 동안 이동할 수 있지만 이동 속도가 점점 느려집니다. 위험 범위 표시가 레제의 몸을 따라다니며, 퓨즈가 끝나면 현재 위치를 중심으로 대폭발(170)을 일으키고 인간으로 돌아옵니다. 체력 12%를 소모하며, 폭탄의 악마는 인간으로 돌아온 뒤 20초 후 다시 쓸 수 있습니다.
- **전체 스킬 시연**: 변신 → 상승 폭발 → 공중 Q 내려찍기 → 오른손 폭발 → 대폭발.
- 레제의 화약 게이지(에너지)는 더 이상 쓰이지 않고 체력이 자원입니다. Q는 앞 대각선으로 높이 솟으며, 공중에서 다시 누르면 내려찍기로 이어집니다.

Roblox 캐릭터 선택은 고죠·젠이츠·레제·샹크스·도라에몽·페인 6명입니다.

**캐릭터 외형(Roblox)**: 플레이어 본인의 아바타·옷은 그대로 두고 상징 부위만 붙입니다. 고죠는 안대, 젠이츠는 허리의 칼, 레제는 쵸커(핀 고리 포함), 샹크스는 오른손 검과 왼팔이 없는 외형, 도라에몽은 배에 밀착한 흰 반달 주머니와 목의 방울이며, E 장착 후 비행할 때 노란 대나무 헬리콥터가 머리에 나타납니다. 레제가 변신하면 원래 머리와 머리 장신구를 숨기고 도화선 머리카락이 달린 폭탄 머리로 바뀌며, 변신이 끝나면 원래대로 돌아옵니다.
- 오른쪽 위 **소리 OFF**를 눌러 사운드를 켤 수 있습니다. 첫 클릭에 WAV 57개를 디코딩한 뒤 **소리 ON**으로 바뀝니다. 기존 스킬 30개 전체와 점프·착지·슬라이딩·평타·도라에몽 도구, 무량공처 내부·종료·파괴 소리에 Kenney의 CC0 녹음층을 넣고 합성음은 에너지감·잔향에 섞었습니다. 준비·발동·적중 프레임마다 다른 큐를 재생합니다. 초기화·캐릭터 교체·소리 OFF에서는 반복음을 정지합니다. PNG·WAV는 단일 HTML에도 내장되어 인터넷 없이 동작합니다. Roblox에서는 영역 내부·종료에 기본 제공 효과음을 임시로 쓰며, 새 WAV의 SoundId는 업로드 후 연결해야 합니다.
- **연출: 저자극**으로 화면 흔들림과 블러를 줄일 수 있습니다.
- **표적·쿨타임 초기화**로 다시 시작할 수 있습니다.

브라우저판은 연출을 직접 조작하며 검토하는 Three.js 프로토타입입니다. Roblox 엔진 실행 화면이나 실제 멀티플레이 화면이 아닙니다. 표적은 스킬을 사용하지 않으므로 브라우저판에서 적의 스킬 봉인을 체감할 수는 없습니다.

## Roblox Studio에서 이어서 실행

1. `InfinityArena-Gojo.rbxlx`를 Studio에서 엽니다.
2. **Play**를 누르면 경기장과 훈련 표적이 생성됩니다.
3. Q / E / R / Shift로 플레이합니다. 1 / 2 / 3 / 4 / 5 키나 오른쪽 위 버튼으로 캐릭터를 바꿉니다. 1인칭 카메라, 손·칼 뷰모델, 스킬 버튼이 들어 있습니다.
4. 실제 PvP는 Studio에서 서버와 두 명 이상의 플레이어로 확인해야 합니다. 이 환경에서는 Studio를 실행하지 않았습니다.

현재 코드는 서버가 에너지, 쿨타임, 아오·아카 3초 대기와 무라사키 합성, 투사체 피해, 아오의 인력, 영역의 지속 피해와 경계를 처리합니다. 영역 배경은 불투명한 검은색이며, 내부에는 별빛이 보입니다. 영역에 갇힌 대상은 걸을 수 있지만 이 프로젝트의 스킬 사용이 차단됩니다. 처음부터 영역 안에 있던 상대를 포획하며 지속 시간은 7.5초입니다. 새 스킬 시스템을 추가할 때도 `DomainLockedUntil` 속성을 확인해야 합니다. 고죠의 에너지 비용·회복·재사용 대기와 영역 지속 시간은 브라우저 시연 수치에 맞췄습니다. 이동 거리·피격 폭처럼 맵 단위가 다른 항목은 Roblox 스터드에 맞게 별도로 조정합니다.

캐릭터 선택은 플레이어 속성 `Character`(`Gojo` / `Zenitsu` / `Reze` / `Shanks` / `Doraemon` / `Pain`)로 서버가 관리하며, 서버는 `GojoConfig.Kits`에 없는 스킬 요청을 거부합니다. 도라에몽의 무작위 도구·공기포 넉백·스몰라이트 축소·헬리콥터 비행·어디로든 문 이동, 젠이츠의 서버 기준 E 충전 시간·10~40스터드 이동·전집중 후 개별 충전 3회·발도당 70 피해, 화뢰신의 초고속 돌진·지연 피해·반동(자기 피해, `SlowedUntil` 이동 저하와 대시 잠금)도 서버가 판정합니다. 젠이츠의 새 발도·잔상 소리는 Roblox에 업로드한 전용 WAV를 아직 연결하지 않았고, 브라우저 프리뷰에는 연결되어 있습니다.

레제의 변신 상태는 캐릭터 모델 속성 `BombDevilUntil`(변신 중에는 매우 큰 값, 대폭발이나 사망 시 0)로 관리되며, 서버는 변신 중이 아니면 상승 폭발·내려찍기·오른손 폭발·대폭발 요청을 거부합니다. 상승 폭발과 공중 재입력 내려찍기, 오른손 폭발, 대폭발, 체력 비용, 변신 회복, 20초 재사용 대기, 넉백도 서버가 판정합니다. R 퓨즈 중 이동 속도는 점차 낮아지고 위험 범위 표시는 캐릭터를 추적합니다. 넉백은 대상이 플레이어면 해당 플레이어의 클라이언트가 속도를 적용하고, 고정된 훈련 표적은 서버가 포물선 궤적으로 움직입니다. 폭발 연출은 Roblox 기본 `Explosion`(압력 0, 관절 파괴 0)에 네온 파트를 더한 것이고, 핀의 “팅” 소리는 Roblox 내장 `rbxasset://sounds/electronicpingshort.wav`를 높은 피치로 재생합니다. 도화선 지글거림 소리는 Roblox판에 아직 없습니다.

맵은 Play 시 생성됩니다. Studio 편집 화면에서 생성 전 맵이 비어 보이는 것은 현재 구현 방식입니다. 손동작은 게시된 애니메이션 파일 없이 코드로 움직이는 초기 뷰모델이며, 최종 손 리깅·모션 캡처·캐릭터 모델은 후속 제작 대상입니다.

**1인칭 팔·손**: 플레이어가 착용한 Roblox 아바타의 팔·손 메시, 피부색, 클래식 셔츠 소매를 사용합니다. 고죠·레제의 평상시에는 손을 화면 아래 양옆에 고정해 걷기·대기 애니메이션으로 흔들리지 않게 합니다. 젠이츠의 칼 잡기와 스킬 전용 동작은 유지합니다. 캐릭터 선택으로 손·소매 색을 강제로 바꾸지 않으며 리스폰·외형 재적용 시 팔을 다시 갱신합니다. 현재 R15 아바타로 Studio 플레이 확인을 진행했습니다.

고죠의 아카·무라사키는 준비 중 카메라 조준을 갱신하고 실제 발사 순간의 조준선으로 날아갑니다. 아카는 눈높이에서 출발하며 지형 충돌 범위(1.2스터드)와 피해 판정 범위(3.5스터드)를 구분합니다.

- `preview/`: 수정 가능한 브라우저 미리보기 소스. 페인은 `preview/pain.js`.
- `ASSETS.md`: 외부 에셋과 직접 제작한 아이콘·효과음의 적용 상태.
- `assets/skill-pack-v1/`: PNG 18개, WAV 57개, 미리듣기 페이지, 생성 프롬프트와 Roblox ID 카탈로그.
- `tools/build-preview-assets.cjs`: 위 파일을 브라우저 프리뷰용 Blob 리소스로 내장. `build-preview.cjs`가 자동 호출합니다.

Rojo로 소스를 변경한 뒤 빌드하는 명령:

```text
rojo build roblox/default.project.json -o InfinityArena-Gojo.rbxlx
```

## 완료 상태와 남은 부분

- 브라우저 3D 미리보기와 로컬 프로젝트 파일 생성 완료.
- Rojo 프로젝트 빌드 성공.
- Roblox Studio 실행·멀티플레이·모바일 성능 확인은 미실시.
- 스토어 모델은 원본 파일이 로컬 프로젝트에 내장된 상태가 아닙니다. 실행 시 로드하며 권한 또는 에셋 상태에 따라 실패할 수 있습니다.
- 브라우저와 Roblox판은 엔진과 효과 구현이 다릅니다. 동일 화질/동일 타이밍의 최종 검수 전 버전입니다.
- 현재 단계는 3캐릭터 훈련장 프로토타입입니다. 매칭, 승패, 랭크, 저장, 수익화, 완성된 외부 캐릭터 모델은 포함하지 않습니다.
- Rojo가 없는 환경에서 수정한 경우 `.rbxlx` 안의 스크립트 소스를 `roblox/src`와 직접 맞췄습니다. Rojo가 있으면 위 명령으로 다시 빌드하는 것이 정석입니다.

기존 계정으로 획득한 에셋 로딩 조건은 Roblox의 [InsertService 문서](https://create.roblox.com/docs/reference/engine/classes/InsertService)를 따릅니다. 그룹 소유 게임으로 옮기면 권한을 별도로 확인해야 합니다.

### 천도 페인 확인 상태

- Luau 4개 파일(`PainAbilityConfig`, `PainServer`, `PainVFX`, `PainClient`)과 수정한 Combat·Arena·Gojo.client는 파서로 문법만 검사했고 `.rbxlx`에 동기화했습니다. **Roblox Studio에서 실행해 보지 못했습니다.** 1인칭 팔 위치, 윤회안·소매 부품 위치, AlignPosition 세기는 Studio에서 보고 조정해야 합니다.
- 브라우저 프리뷰는 헤드리스 Chromium에서 프레임을 캡처해 Q/E/R 전 과정을 확인했습니다.
- 맵 파괴는 파괴 가능 표시가 있는 물체가 없어 복사한 바위 파편과 임시 크레이터로만 표현합니다.
